# 14 — Glossário

- **Shadow AI**: uso não governado de IAs por colaboradores.
- **eBPF**: programas seguros no kernel Linux p/ observabilidade/segurança sem módulos.
- **JA4**: fingerprint de ClientHello TLS p/ identificar apps/SDKs sem decifrar.
- **OPA/Rego**: motor de políticas como código.
- **DLP**: Data Loss Prevention — impedir saída de dado sensível.
- **WORM**: Write Once Read Many — imutabilidade de armazenamento.
- **Hash chain**: encadeamento de hashes p/ integridade da auditoria.
- **SCC**: Security Context Constraints (OpenShift).
- **SISP / APS**: Sistema de Administração de Recursos de TI / Análise de Pontos por Função (contratação pública BR).
- **LGPD**: Lei 13.709/2018. **Marco Legal da IA**: Lei 14.879/2024. **LAI**: Lei 12.527/2011.
- **Ready/Liveness/Startup probes**: checagens do K8s (pronto p/ tráfego / vivo / boot).
- **GitOps**: o estado desejado vive no Git; o cluster converge p/ ele (ArgoCD).
